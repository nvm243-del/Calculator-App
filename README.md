# Calculator App

A simple calculator web application built using HTML, CSS, and JavaScript,
developed as part of Assignment 01 for the Software Engineering course
(COMSATS University Islamabad, Wah Campus).

## Purpose

This project demonstrates a basic web application built and deployed using
a DevOps workflow — including version control with Git/GitHub, continuous
integration with GitHub Actions, and deployment via GitHub Pages.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Decimal point support
- Clear (C) button to reset the display
- Simple, easy-to-use interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS, no frameworks)

## How to Run Locally

1. Clone or download this repository
2. Open `index.html` in any web browser
3. Start calculating!

## Files

| File         | Purpose                          |
|--------------|-----------------------------------|
| `index.html` | Page structure and buttons        |
| `style.css`  | Styling and layout                |
| `script.js`  | Calculator logic                  |
